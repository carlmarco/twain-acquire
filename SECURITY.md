# Security

## Reporting a vulnerability

Report it privately through GitHub: open the repository's **Security** tab and
choose **Report a vulnerability**. Do not open a public issue for it.

Include the version (Windows Settings > Apps, or the installer file name), the Windows version,
and the steps that show the problem. You will get an answer when the report has
been read; please keep it private until a fixed release is out.

## No patient data

Never send patient data with a report: no images, DICOM or TIFF files, patient
names, IDs or dates of birth, and no screenshots that show them. Read any log
or settings file before sending it, and remove file and folder paths that
contain patient details. If a problem only shows with a particular image,
describe the image (size, bit depth, source) instead of sending it.

## Supported versions

Only the latest release receives fixes.
